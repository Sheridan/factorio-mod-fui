# FUI (Factorio User Interface)

FUI is a lightweight library mod for Factorio that provides a structured API for creating and managing in-game Graphical User Interfaces (GUIs).

## Overview
This mod does not alter vanilla gameplay, add items, or change mechanics. It is strictly a library intended for other mod developers to simplify GUI creation, state management, and component rendering.

## Features
- **Core Components:** Pre-built abstractions for windows, tables, and tabbed panes (`fui.window`, `fui.table`, `fui.tabbedpane`).
- **State Management:** Automatic initialization and handling of mod storage for GUI states.
- **Event Handling:** Built-in handlers for GUI events.
- **Zero Footprint:** No dependencies, no gameplay changes.

## Installation
1. Download the mod from the Factorio Mod Portal.
2. Place it in your `factorio/mods/` directory.
3. Enable it in the game's mod menu.
